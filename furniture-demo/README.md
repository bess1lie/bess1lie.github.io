# Столярная мастерская «Ағаш» — демо-версия

Адаптивный одностраничный сайт мебельной мастерской: услуги и цены,
галерея работ, отзывы, частые вопросы, кнопки звонка / WhatsApp / Telegram
и форма заявки.

## Демонстрационные данные

- **Телефон, WhatsApp, Telegram, адрес** — вымышленные, для примера.
- **Форма заявки** — демонстрационная: при отправке показывает
  подтверждение, но никуда не отправляет данные.
- **Изображения** — стилизованные заглушки вместо реальных фото.

## Быстрый запуск

Откройте `index.html` в любом браузере — сайт работает полностью офлайн,
без сервера и интернета.
